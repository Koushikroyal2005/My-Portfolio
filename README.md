# My Portfolio

Interactive software-engineering portfolio for Koushik Kotte, built with React and vinext. The interface switches between Naruto-inspired light mode and Sasuke-inspired dark mode, with a canvas-based portrait reveal and responsive motion throughout.

## Run locally

    npm install
    npm run dev

Open the local URL shown in the terminal.

## Validate

    npm test

## Project structure

- app/components/ — reusable portfolio sections and interactions
- app/data/ — projects, experience, certifications, and skills
- app/globals.css — theme tokens, responsive layout, and animation styles
- public/assets/ — optimized portfolio artwork and profile assets
- tests/ — server-render and asset checks
